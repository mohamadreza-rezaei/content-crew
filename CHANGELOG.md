# Changelog

## 0.2.0 (2026-10-26)
- Experience-first voice mandatory for Writer/Humanizer handoffs (ban README/intro framing).
- Higher visual bar for carousel slides; unique art preferred over reused flat mascot art.
- Optional channel caption + short-form draft outputs; short-form image = hero twin, not a new composition.
- Standing permission supported for named platforms; draft-to-owner path for free/paywalled short-form (e.g. X).
- Post-publish: channel single-photo + private short-form delivery alongside topic announcement.
- Default schedule guidance: twice a day (flexible), not 2–3.
- Checklist and folder layout updated for extras and experience voice.

## 0.1.1 (2026-10-24)
- Experience-first copy. Posts and captions lead with installed, used-for-a-while experience, then the tool. They read as practitioner notes, not tool intros or a product pitch. No invented anecdotes; use docs or first-run framing only when that is the honest experience.
- Higher bar for slide art. Backgrounds and color palettes should be modern, professional, distinctive and attractive. Prefer unique art, and redo bland, low-contrast, or reused flat mascot slides.
- Pre-handoff checklist and README Why section updated to match. Skill body synced to the owner's latest pipeline text.

## 0.1.0 (2026-10-23)
- First release: `multi-brand-content-pipeline` skill (9-stage pipeline, dedupe, fact files, writer → humanizer → video → publisher handoffs, approval gate, post-publish announcement).
- `render.py` carousel renderer with 3 themes and hero/card/cta layouts.
- `check_lines.py` RTL line-start checker, pre-handoff checklist.
- Claude Code plugin + marketplace manifests, example brand guide, facts, brief, slide config and dedupe log.
